# Rust to Shine

A 3D restoration game. Soak rusty tools and toys in vinegar, wire-brush the rust away, sand, sharpen, hammer out dents, swap broken parts, repaint and polish, then drag the before/after slider to see the difference. Finished jobs earn coins for new paint colors.

Play it at https://brandrisk4.github.io/Rust-to-Shine/ and add it to your home screen:

- **iPhone (Safari):** tap Share, then "Add to Home Screen".
- **Android (Chrome):** tap the ⋮ menu, then "Install app".

It works offline after the first load. If you change any file, bump `VERSION` in `sw.js` so installed copies update.
